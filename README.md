# re:flex

`re:flex` is a small Expo React Native app for iOS and Android. The first game is a button-release reflex test built for older adults with large controls, clear timing, and a simple three-round average score.

## Game 1: Button Release

- The target time is randomized each round.
- The button starts red.
- Holding the button turns it green and starts a timer from `0.000`.
- The player releases as close as possible to the target time.
- Each session has 3 attempts and reports the average score.

## Run

```sh
npm install
npm start
```

Then open the project in Expo Go or a development build for iOS or Android.

## Useful Commands

```sh
npm run ios
npm run android
npm run doctor
```
